# DJS MicroMinds — Semester 3 Digital Design Repository

This repository documents my progress through the Semester 3 roadmap covering Digital Electronics, Verilog HDL, Electronic Devices & Circuits, and FPGA implementation on the Basys 3 (XC7A35T-1CPG236C).

## Repository Structure

```
Digital_Electronics/   — Theory notes and concept summaries
Verilog_Designs/       — RTL modules with testbenches and simulation results
LTspice_Simulations/   — Analog circuit simulations (EDC section)
Projects/              — Traffic Signal Controller & 8-Bit ALU
```

## Tools

| Tool | Purpose |
|------|---------|
| AMD Vivado ML 2024.2 (Standard Edition) | RTL entry, XSim simulation, synthesis, implementation, bitstream |
| Icarus Verilog + GTKWave | Quick local simulation on macOS |
| LTspice | Analog circuit simulation (EDC only) |
